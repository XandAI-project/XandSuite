# XandSuite

A local LLM desktop application built with Rust, Tauri v2, and React. XandSuite is a full-featured AI assistant platform that lets you download, manage, and run GGUF models locally or connect to any remote OpenAI-compatible server — with an extensible tool/package system, rich chat rendering, and a clean dark-themed desktop UI.

---

## Features

### Chat
- Streaming token output with full markdown and syntax highlighting
- Tool call visualization — expandable cards showing arguments and results inline
- **Artifact Panel** — right-side panel for code, markdown, HTML, CSV, JSON, and PDF artifacts generated during chat
- **Gallery Panel** — per-conversation and global image/video gallery; images saved locally and served offline
- Inline HTML rendering for rich responses (charts, tables, metric cards) generated by tool packages
- Stop generation at any point, including during active tool calls
- Conversation management: create, rename, delete, truncate

### Personas
- Create AI personas with custom system prompts, model overrides, and avatars
- Per-persona RAG collection binding and memory settings

### Prompt Templates
- Reusable prompt library with categories, keyboard shortcuts, and variable placeholders
- Built-in templates for image generation, video generation, image editing, Jellyfin, and rich responses
- "Requires package" chip — templates are tagged with the package they depend on

### Models
- Browse and download GGUF models directly from HuggingFace with search and filtering
- Manage locally downloaded models; delete models to reclaim disk space
- Connect to any remote OpenAI-compatible server (llama-server, LM Studio, Ollama, etc.)
- GPU detection and bundled llama-server lifecycle management

### RAG (Knowledge Base)
- Create collections; ingest PDFs, CSVs, JSON, plain text, and code files
- Automatic chunking, embedding, and vector search
- Hybrid retrieval mode and optional graph indexing

### Skills / MCP Servers
- Connect any external MCP (Model Context Protocol) server over stdio
- Manage custom tool servers via URL or command
- Direct tool call testing from the UI

### Packages
- Install official and custom Python-based tool packages
- Each package runs as a FastMCP subprocess, exposing typed tools to the LLM
- Automatic pip dependency installation per package

### Official Packages

| Package | Description |
|---------|-------------|
| **Jellyfin** | Search and browse a Jellyfin media server by title, genre, year, and type |
| **ComfyUI Image Generation** | Generate images from API-format ComfyUI workflows with automatic prompt injection |
| **ComfyUI Image Editing** | img2img editing — upload an image, inject into LoadImage nodes, run the workflow |
| **ComfyUI Video Generation** | Generate videos from ComfyUI workflows with frame/dimension placeholders |
| **Rich Responses** | Generate inline charts, tables, metric cards, and comparison grids as pure SVG/HTML |
| **PDF Tools** | Read PDFs (text, tables, metadata) and generate PDF documents and reports, fully offline |

### Flow Builder
- Visual drag-and-drop node editor (React Flow) for automated prompt pipelines
- Persist and execute flows with per-node result tracking

### Coding Mode *(optional, env-gated)*
- Project-based coding agent with file explorer, task planning, and terminal output
- Session management with message history and plan tracking

### Agents
- Multi-step ReAct-pattern agent tasks with workspace file access
- Background execution with status tracking and cancellation

### Whisper (Voice Input)
- Local speech-to-text via Whisper binary
- Binary and model download from within the app

### Database Connectors
- Connect to MongoDB, PostgreSQL, and MySQL
- Run queries directly from the UI; results rendered in chat

### HTTP API
- Built-in Axum HTTP/SSE server for mobile or remote frontend access
- Tool call and result streaming via Server-Sent Events
- Gallery and image serving endpoints for offline media

### Artifacts
- All code, documents, HTML pages, CSVs, JSONs, and PDFs generated during chat are automatically saved as artifacts
- Artifact panel with syntax highlighting, CSV viewer, JSON tree, inline HTML iframe, and PDF viewer
- Edit, download, and delete artifacts; export HTML artifacts to PDF

### Gallery
- Generated images and videos saved to a local SQLite-backed gallery
- Served via a local HTTP endpoint for fully offline access (no external URLs)
- Per-conversation and global view

## Tech Stack

| Layer | Technology |
|---|---|
| Desktop shell | Tauri v2 |
| Frontend | React 19, TypeScript 5.8, Vite 7, Tailwind CSS v4 |

| Backend | Rust (Tokio async runtime) |
| HTTP layer | Axum (internal API + SSE server) |
| LLM inference | llama-server process or `llama-cpp-2` crate (optional feature) |
| Database (app state) | SQLite (rusqlite, bundled, WAL mode) |
| Database connectors | MongoDB (mongodb crate), PostgreSQL / MySQL (sqlx) |
| HTTP client | reqwest 0.12 with native-tls |
| RAG vector store | oasysdb (in-memory + JSON persistence) |
| Tool packages | Python 3.9+ FastMCP subprocesses (JSON-RPC 2.0 over stdio) |
| PDF generation | fpdf2 (Python, offline) |
| PDF reading | pdfplumber (Python, offline) |
| File opener | tauri-plugin-opener |
| Testing | Vitest (frontend), cargo test (Rust) |

## Prerequisites

### Required

| Tool | Minimum version | Notes |
|---|---|---|
| [Node.js](https://nodejs.org/) | 20 LTS | Includes npm |
| [Rust](https://rustup.rs/) | 1.80+ | Install via `rustup` |

- **WebView2** — pre-installed on Windows 11; on Windows 10 install the [WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)
- **Microsoft Visual Studio Build Tools 2022** (C++ workload) — required by Rust crates that compile C dependencies (rusqlite bundled, etc.)

### Linux-specific

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y \
  libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev \
  librsvg2-dev patchelf curl build-essential pkg-config libssl-dev
```

If you want to run inference directly through the `llama-cpp-2` Rust crate (instead of via the bundled llama-server process):

- **cmake** 3.20+
- **clang** (Linux) or **MSVC** (Windows, included with Visual Studio Build Tools)
- CUDA Toolkit 12.x (for GPU acceleration)

## Getting Started

### 1. Clone and install dependencies

```bash
git clone https://github.com/xandnet/xandsuite.git
cd xandsuite
npm install
```

### 2. Configure environment (optional)

```bash
cp .env.example .env
```

```env
# .env
HF_API_TOKEN=hf_your_token_here        # HuggingFace token (optional, increases rate limits)
REMOTE_LLM_URL=http://localhost:8080   # Pre-configured remote llama.cpp server (optional)
```

### 3. Run in development mode

```bash
npm run tauri dev
```

This starts the Vite dev server on `http://localhost:1420` and compiles the Rust backend. The first compile takes several minutes as it builds all Rust dependencies.

### 4. Run frontend-only (no Tauri window)

```bash
npm run dev
```

Useful for rapid UI iteration. Tauri `invoke` calls will fail gracefully since there is no backend.

## Building for Production

```bash
npm run tauri build
```

Output installers are placed in `src-tauri/target/release/bundle/`:

|---|---|---|
| Windows | `.msi` + NSIS `.exe` | `bundle/msi/`, `bundle/nsis/` |

### Build with local llama-cpp-2 inference enabled

```bash
# CPU only
npm run tauri build -- -- --features local-llm

# With CUDA support
npm run tauri build -- -- --features local-llm,cuda
```

## Tool Packages

Tool packages are Python scripts that expose typed tools to the LLM via the Model Context Protocol (MCP) over stdio. The app installs, manages, and spawns these as subprocesses.

### Adding a Custom Package

1. Open **Packages** in the sidebar
2. Click **Add Custom Package**
3. Provide a name, path to your Python script, and any required arguments
4. The app will install pip dependencies and connect the MCP server automatically

### Official Package Details

#### Jellyfin
Connect to a self-hosted Jellyfin media server. The LLM can search your library, browse by genre or year, and retrieve recently added media.

**Required args:** `url`, `api_key`

#### ComfyUI Image Generation
Generate images using any ComfyUI workflow. The package auto-injects your prompt into `CLIPTextEncode` nodes or `__POSITIVE_PROMPT__` / `__NEGATIVE_PROMPT__` placeholders.

**Required args:** `url`, `workflow_file`

#### ComfyUI Image Editing
Edit existing images using img2img ComfyUI workflows. Attach an image in chat and ask the LLM to edit it — the package uploads the image, injects it into `LoadImage` nodes, and runs the workflow.

**Required args:** `url`, `workflow_file`

#### ComfyUI Video Generation
Generate videos using ComfyUI workflows with `__FRAMES__`, `__WIDTH__`, and `__HEIGHT__` placeholders.

**Required args:** `url`, `workflow_file`

#### Rich Responses
Generate rich inline content (line charts, bar charts, pie charts, data tables, metric cards, comparison grids) rendered directly in the chat as pure SVG/HTML — no internet required.

**No args required.**

#### PDF Tools
Read and generate PDFs entirely offline.

- **Read:** extract text by page range, extract tables, get metadata
- **Write:** create simple documents or structured multi-section reports

**Optional args:** `output_dir` (default: user's Downloads folder)

## Database Schema

The app stores all state in a single SQLite database (`xandsuite.db`, WAL mode):

| Table | Purpose |
|---|---|
| `conversations` | Chat threads with title, model, system prompt, persona |
| `messages` | All messages per conversation with metadata and tool steps |
| `artifacts` | Code, HTML, markdown, CSV, JSON, and PDF artifacts tied to messages |
| `gallery_images` | Base64-encoded generated images and videos |
| `personas` | AI persona definitions (system prompt, model, RAG, memory flags) |
| `prompt_templates` | Built-in and user-defined prompt templates with `requires` package field |
| `flows` | Visual flow definitions (nodes + edges JSON) |
| `flow_executions` | Flow run history and per-node results |
| `agent_tasks` | Agent task metadata and steps |
| `comfyui_workflows` | Stored ComfyUI workflow JSON by name |
| `rag_collections` | RAG collection metadata (retrieval mode, graph index) |
| `rag_documents` | Ingested documents per collection |
| `db_connections` | Saved external database connection strings |
| `coding_sessions` | Coding agent sessions |
| `coding_messages` | Coding session messages with events |
| `coding_plans` | Task plans per coding session |
| `settings` | Key/value application settings |

## Using a Remote llama.cpp Server

XandSuite can connect to any OpenAI-compatible endpoint (llama-server, LM Studio, Ollama, vLLM, etc.):

1. Open **Models** → **Remote Server** tab
2. Enter the server URL, e.g. `http://localhost:8080`
3. Enter an API key if required
4. Click **Connect** — the app will verify the connection and activate the engine

The remote engine sends requests to `/v1/chat/completions` with streaming enabled.
